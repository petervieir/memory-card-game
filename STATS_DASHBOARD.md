# Statistics Dashboard

Comprehensive performance tracking and game history.

## Overview Stats

- Total games played and won
- Win rate percentage
- Achievement completion
- Total points earned
- Total play time

## Per-Difficulty Stats

For each difficulty level:
- Games played
- Win rate
- Average moves
- Best moves
- Best score
- Best completion time

## Features

- **Move Efficiency Graph** - Visual tracking over last 20 games
- **Recent Games Table** - Last 5 games with details
- **Achievement Breakdown** - Progress by category
- **Difficulty Filtering** - View stats by difficulty

## Data Tracked

- Move count
- Score earned
- Hints used
- Combo achieved
- Timer mode status
- Completion status
