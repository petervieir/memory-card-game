# Hint System

Strategic assistance system for revealing matching cards.

## How It Works

- **Cost**: 50 points per hint
- **Limit**: 1-3 hints per game (based on difficulty)
- **Effect**: Reveals 3 matching cards for 3 seconds
- **Trade-off**: Balance point preservation with assistance

## Difficulty Limits

| Difficulty | Max Hints |
|------------|-----------|
| Beginner | 3 |
| Intermediate | 2 |
| Advanced+ | 1 |

## Strategy

- Use hints when stuck to save moves
- Consider point cost vs. efficiency bonus
- No-hint runs unlock achievements
- Efficient hint usage rewarded

## Achievements

- **No Hints Master** - Complete without hints
- **Strategic Thinker** - Efficient hint usage on difficult levels
