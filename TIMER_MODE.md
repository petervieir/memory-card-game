# Timer Mode

Optional time-based gameplay with countdown timer.

## Features

- **Countdown Timer**: Difficulty-based time limits (60-120 seconds)
- **Time Bonus**: 2 points per second remaining
- **Visual Feedback**: Color-coded progress bar
- **Sound Warnings**: Alerts at 20s and 10s remaining
- **Time's Up**: Game ends if timer reaches zero

## Timer Durations

| Difficulty | Time |
|------------|------|
| Beginner | 60s |
| Intermediate | 90s |
| Advanced | 100s |
| Expert | 110s |
| Legend | 120s |
| Master | 120s |

## Achievements

- **Time Attack Winner** - Complete a timer mode game
- **Speed Demon** - Complete with 50%+ time remaining
- **Last Second Hero** - Complete with <10s remaining
- **Time Attack Master** - Complete Master difficulty in timer mode
- **Clock Beater** - Complete 10 timer mode games

## Scoring

Time bonus added before combo multipliers:
```
Score = (Base + Efficiency + Time Bonus) × Combo × Difficulty
```
