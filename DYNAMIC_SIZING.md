# Dynamic Card Sizing

Automatic card sizing based on screen size and grid density.

## How It Works

- Cards automatically resize based on window dimensions
- Grid density adaptation for higher difficulties
- Maintains 4:5 aspect ratio
- Responsive gaps between cards

## Size Ranges

- **Mobile** (< 640px): 48px - 80px width
- **Tablet** (640px - 1024px): 64px - 96px width
- **Desktop** (> 1024px): 80px - 120px width

## Features

- Real-time window resize handling
- Icon scaling with card size
- Gap adjustment based on card size
- Optimal gameplay on all devices
