# Combo System

Rewards consecutive successful matches with score multipliers.

## How It Works

- **Consecutive matches** build combo streaks
- **Combo resets** to 0 on mismatches
- **Multipliers** apply to final score

## Multiplier Tiers

| Combo | Multiplier | Visual |
|-------|------------|--------|
| 0-2 | 1.0x | None |
| 3-4 | 1.2x | Yellow badge |
| 5-9 | 1.5x | Orange badge |
| 10+ | 2.0x | Red badge + pulse |

## Visual Feedback

- Color-coded badges show active combo
- Pulse animations at milestones (3x, 5x, 10x)
- Toast notifications explain multipliers
- Best combo shown in game summary

## Achievement

**Combo Master** 🔥 - Achieve a 10+ combo streak

## Strategy

- Focus on memory to build long combos
- Avoid random guesses (they break combos)
- Plan ahead for consecutive matches
- Higher combos = dramatically higher scores
