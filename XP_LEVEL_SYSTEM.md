# XP & Level System

Long-term progression system separate from points.

## XP Sources

- **Base Game**: 50 XP per completion
- **Difficulty Multipliers**: 1.0x to 2.5x
- **Perfect Game**: +50 XP bonus
- **Combo Bonuses**: +5 XP per combo above 5
- **Achievements**: +100 XP per unlock
- **Daily Challenges**: +150 XP
- **Daily Login**: +25 XP (with streak bonuses)

## Level Progression

- Exponential curve: `100 * level^1.5`
- Unlimited level cap
- Automatic level-up detection
- Multi-level ups supported

## Player Titles

- **Novice** (Level 1)
- **Apprentice** (Level 5)
- **Adept** (Level 10)
- **Expert** (Level 25)
- **Memory Master** (Level 50)
- **Grandmaster** (Level 75)
- **Immortal** (Level 100)

## Unlockables

- **Card Borders**: Blue, Green, Purple, Gold, Rainbow
- **Card Backs**: Galaxy, Fire, Ice, Diamond

## Daily Login

- Automatic XP on first login
- Streak tracking
- Bonus XP for 7+ day streaks (+25 XP)
- Bonus XP for 30+ day streaks (+50 XP)
