# Contributing

Guidelines for contributing to the Memory Card Game.

## Quick Start

1. Fork and clone the repository
2. Install dependencies: `npm install`
3. Start development: `npm run dev`
4. Make changes following guidelines
5. Submit a pull request

## Checklist

### Code Quality
- [ ] Follows existing style conventions
- [ ] TypeScript types defined
- [ ] ESLint passes
- [ ] Code commented
- [ ] No console.log in production

### Testing
- [ ] Manual testing completed
- [ ] Multiple screen sizes tested
- [ ] Wallet integration tested
- [ ] Tests added/updated

### Documentation
- [ ] README.md updated
- [ ] FEATURES.md updated (if new features)
- [ ] CHANGELOG.md updated
- [ ] Code comments added

## Types of Contributions

- **Bug Fixes** - Include reproduction steps
- **New Features** - Discuss in issues first
- **Documentation** - Always welcome
- **UI/UX** - Test across devices

## Commit Messages

Use conventional commits:
- `feat:` - New feature
- `fix:` - Bug fix
- `docs:` - Documentation
- `refactor:` - Code refactoring
